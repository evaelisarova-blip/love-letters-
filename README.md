# Universal Love Letters

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
1. Create a GitHub repo.
2. Push this project.
3. Run:
```bash
npm install
npm run build
npm run deploy
```

If you want to deploy under a repo path like `/my-repo/`, change `base` in `vite.config.js` from `./` to `/my-repo/`.
